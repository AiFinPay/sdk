# Casper Splitter — Contract Registry

## Deployment lookup

Casper deployments use a contract hash and contract schema rather than an EVM contract suite. Read [deployments.json](deployments.json) for network, environment, contract hash, schema metadata and settlement flag.

## Supports

Current network was deprecated and removed from AiFinPay SDK v1.4. The Casper Splitter contract is no longer supported for settlement.
Deployment records are retained for historical reference and verification of past transactions. Do not attempt to use these records for new settlements.
