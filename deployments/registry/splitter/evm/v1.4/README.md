# B2BSplitter v1.4 — Full Contract Suite Deployments

## Overview

v1.4 is a **complete protocol deployment** — not just a splitter contract, but a full suite of contracts working together:

**Contracts:**
- `splitter` — Payment settlement
- `tokenList` — Allowed assets
- `profiles` — Agent/merchant identity profiles
- `admin` — Administrative control
- `signer` — Signature verification
- `pauser` — Emergency pause control
- `treasury` — Fee recipient

**Status:** Mostly disabled. Only Amoy (testnet) is enabled. Production deployments await backend v1.4 receipt verification and end-to-end settlement gate completion.
